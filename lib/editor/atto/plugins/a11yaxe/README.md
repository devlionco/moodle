Content accessibility Atto plugin for moodle
============================================

Install via gui by dragging and dropping the zip into the admin plugin install page or unzip it into the folder:
lib\editor\atto\plugins

Add it to editor in Site administration->Plugins->Atto toolbar settings->Toolbar config

This is a Moodle plugin for Accessibility for the Atto editor that uses the Axe core JS library:
https://github.com/dequelabs/axe-core
